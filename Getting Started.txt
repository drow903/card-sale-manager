CARD SALE MANAGER — GETTING STARTED
POST. SELL. TRACK.
From first claim to final shipment.

FIRST RUN

The setup wizard chooses Beginner or Standard mode, your shipping defaults, primary image folder, and
optional seller name. Keep the fictional sample sale to follow the built-in
guided walkthrough without using real customer information. You can reopen
Setup and the walkthrough from Help & Guide at any time.

The Command Center is the default starting page. Green actions move work
forward. Amber or red items need review. Its checklist links directly to
pending offers, unpaid orders, address problems, missing images, and work that
is ready to pack or ship.

PORTABLE CSM FILES

Choose Portable CSM file in the sidebar to save the complete workspace as a
.csm file. Store it in OneDrive to open the same sale on another computer with
Card Sale Manager installed. CSM continues keeping its normal local recovery
copy while the portable file is open, and changes autosave to both locations.

If OneDrive is in a different location, CSM first repairs image links using
relative paths. If images are still missing, choose Relink image folder and
select the main card-image folder once. Create package with images makes a
self-contained folder when you do not want to rely on the original paths.

Do not edit the same .csm file on two computers at once. CSM uses a lock file,
opens a file read-only when it may be in use elsewhere, and refuses to replace
a newer cloud revision without confirmation. Verified backups are stored in a
.csm-backups folder beside the portable file. Ctrl+O opens a CSM file and
Ctrl+S saves one.

The Portable CSM file screen can restore those recovery copies, review missing
images one at a time, and maintain the recent-file list. Recent files can be
pinned, shown in File Explorer, or removed from the list. If a file has changed
on another computer, CSM automatically saves a conflict copy and offers three
choices: stay read-only, save the local work as a new file, or take over editing.
Take over only after the other computer has closed the file.

VERSION 1.9 WORKSPACE TIPS

Claims Desk now uses the full available height. The card table and Recent
Claims scroll separately. Collapse Recent Claims or use its width slider when
you need more table space; CSM remembers the setting. Alt+Up and Alt+Down move
between the same field on neighboring claim rows, and Enter saves the row.

The Facebook sale link saved during setup is available from Command Center,
Live Sale Mode, Claims Desk, and Buyer Orders. Live Sale Mode shows the exact
filename under each image and can copy it, copy the full path, reveal the file,
open related-image review, or remove the association and rematch it.

Address Review is local and advisory. It checks city/state/ZIP layout, state
abbreviations, ZIP length, duplicate lines, PO boxes, shared addresses, and
changes from a buyer's previous address. Always confirm the final address with
the buyer.

Performance mode defaults to Auto and helps very large sales avoid rendering
off-screen rows and cards until needed. Cycle Auto, On, and Off from the
sidebar if you are troubleshooting an older computer.

Archived Sale Records can permanently remove an empty mistake or unwanted
record. CSM shows exact impact counts, leaves buyer profiles and source images
alone, and creates a complete recovery backup before it deletes the record.

1. Double-click Card Sale Manager.exe.
2. Choose New sale and give the sale a name.
3. Choose Guided sale setup when you have both a spreadsheet and images. Drop
   the spreadsheet, individual images, or an image folder onto the same screen.
   CSM identifies each item and carries everything into one review. You can
   still choose Add single card or Import spreadsheet separately.
4. Use these spreadsheet columns: Year, Brand, Player, Number, Flaw(s),
   Grade, Claim Price, Purchase Price, and Purchase Date. Purchase fields are
   kept private. Purchase Price warns when an offer is below cost, while a
   Purchase Date in MMDDYYYY format helps match duplicate-card filenames. Confirm the
   detected columns and edit the listing format if desired. The import Fix
   Center groups missing information, invalid prices, questionable dates,
   duplicates, and unusual prices. Use Fix together for repeated values. After
   a successful import, CSM remembers that spreadsheet layout and applies the
   same mapping automatically next time. Sale reference numbers are generated
   automatically.
5. Choose Add images to open the guided image screen. You can use automatic
   folder matching, attach a group of images in exact sale order, drop images
   directly onto individual cards, or select ordinary image files manually.
   Correctly named files help automatic matching, but filenames are not required.
6. For automatic matching, open Advanced image folders and set the primary
   folder containing your year folders. Add or exclude multiple folders at once.
   These settings carry over to every sale. Unique 100% matches are attached
   automatically; genuinely ambiguous matches appear in Image Review with the
   reason they were suggested and the reason approval is required. Use Compare
   images to inspect competing files side by side. Related-image review shows
   complete file names, paths, purchase-date decisions, and every candidate for
   the duplicate group. You can drop the correct file onto a row, remove a bad
   association without deleting the source image, and re-run the whole group.
   Missing Images Workspace
   gathers every card that still needs a front, back, or single image.
   A purchase-date code is also auto-confirmed when only one copy of that card
   has that purchase date. A valid but different filename date is rejected, not
   merely given a lower score. Same-card duplicates with the same date use their
   final sequence number and remain in review if more than one assignment is safe.
7. For filename-free batch attachment, select cards with their checkboxes. Use
   Shift-click or Select range when the cards are continuous, then choose Attach
   images in order. Select the image files in the same order the cards appear in
   the sale. CSM shows a numbered card-to-image preview before anything changes.
   Check every pairing, reorder or remove images if needed, and confirm that the
   photos were taken or selected in sale order. A count mismatch is blocked unless
   you deliberately allow a partial batch. In front/back sales, choose whether
   files alternate front/back or contain all fronts followed by all backs.
   To attach one card at a time, drag an image onto that card's row or use its
   Add image button. CSM will not reuse the same file on multiple listings.
   Image inbox shows files that have been added but are not attached yet. Assign
   one directly to a card, add more images, or send selected cards to ordered
   pairing.
8. Copy a single listing line from the sale workspace. That card row is hidden
   after copying so the next card moves up. Use the Copied filter to restore it,
   or press Ctrl+Z immediately to undo the hide.
9. Drag an image from the post queue into Facebook. The image hides after the
   drag finishes. This is separate from copying the listing; Ctrl+Z restores the
   most recently hidden card or image.
10. The Claims desk always mirrors every card in the sale workspace. Choose
    Claim or Offer, enter the buyer, and enter an accepted price for offers.
    Offers below Purchase Price are highlighted. A pending offer does not create
    a permanent buyer profile; accepted claims, accepted offers, orders, and
    manually saved profiles do.
    To record one offer for several cards, select the available cards in Sale
    Workspace and choose Bundle offer. Enter the buyer and the total offer.
    Accepting or countering the bundle distributes that exact total across the
    cards in proportion to their list prices, including any penny adjustment.
11. Choose PWE or PMWT for each buyer in Buyer orders, then review totals,
    discounts, and payment status.
12. Delete unwanted cards from the sale workspace. In Packing, verify cards
    individually or choose Check all cards, enter the tracking number, and copy
    the ready-to-send shipping message.
13. Use row checkboxes for bulk deletion and image-review confirmation.
    Duplicate cards are labeled (1 of x). Date-coded filenames (MMDDYY, MDDYYYY,
    or MMDDYYYY) and a final sequence number such as 1 or 2 break ties.
    Re-run lookup on a card to recheck it together with any cards that shared
    the same suggestion. Re-run lookup for every sale deliberately resets and
    rechecks all current and past-sale image links. One file can never be linked
    to more than one listing anywhere in the workspace.
14. The app checks for GitHub releases when it opens. Use Check for updates in
    the sidebar at any time. Confirm the update once and the app downloads and
    installs the Windows setup file automatically.
15. Use Live Sale Mode for a keyboard-first posting workflow. Press ? inside
    the app to see all available shortcuts.
    Command Center also shows Sale preparation counts. Open Fix Center to group
    missing card information, prices, images, and optional teams, or choose Fix
    next problem to work through the list one card at a time. Preparation badges
    appear beside each listing in Sale Workspace.
16. Extra spreadsheet columns can be retained as Custom Fields. Use Custom
    fields in Sale Workspace to control whether each field stays private,
    appears in copied listings, or prints on packing slips. These fields are
    also searchable and available as listing and pulling sort options.
17. Use References in Sale Workspace to keep listing numbers sequential after
    deletion or reordering. CSM's permanent internal card IDs keep images,
    claims, offers, and audit history connected even when a reference changes.
    Freeze references once posted if you do not want automatic renumbering.
18. Card Pulling Mode can sort and group sold cards by buyer, year, player,
    price, purchase date, location, or any imported custom field. Check cards
    as they are pulled or preview a printable pull sheet in the same order.
19. The Notification Center collects pending offers, unpaid orders, missing
    addresses, unmatched images, below-cost sales, pulling/packing work,
    missing tracking, and portable-file warnings. Open an item to jump directly
    to it, or snooze/dismiss it.
20. Buyer Profiles stores tags, notes, addresses, purchase history, and likely
    repeat-buyer matches. Profit Dashboard includes private inventory aging.
21. Before finishing a sale, use Health Check and the Sale Closing Assistant to
    review missing images, incomplete orders, unpaid buyers, and unsold cards.
22. Sale Presets saves reusable shipping prices and listing formats.
    Use Edit beside any listing for the quick-edit drawer, or Move to enter an
    exact card position without dragging.
23. In Packing, choose Customize slips to open the Packing Slip Studio. Add a
    logo, brand name, colors, messages, links, and a QR destination; choose the
    fields to show; drag sections into a preferred order; preview the result;
    and save reusable designs. QR codes are generated locally.
24. Choose Print all slips to filter orders by payment, packing, shipping, or
    prior print status. Select any buyers, then print them in one job or save a
    combined PDF. Successful output is recorded in Print history, and reprints
    are clearly labeled. Available formats include letter, half-sheet, two-up,
    4 x 6 label, and compact inserts. The built-in Card Sale Manager logo and
    green accent are the default; a custom seller logo and colors can still
    replace them. PWE labels have a separate editable 4 x 6 thermal-label
    designer with portrait and landscape layouts, font, alignment, padding,
    color, and optional-section controls. The live preview matches the saved
    orientation used for individual and batch printing.
25. The Theme button cycles between System, Light, Dark, and High Contrast. The Motion button
    reduces animation. These preferences are remembered, but printed packing
    slips always use a clean white background.

Data is saved automatically on this computer and again when the app closes.
Verified recovery backups are also created before updates and retained locally.
Every approved update additionally creates a permanent, non-rotating archive
under the app data folder's update-archives directory. It includes the complete
local workspace and any open portable .csm file. Update archives are never
removed by CSM. Startup also checks daily backups, update archives, and older
CSM data folders before showing first-run content. Buyer profiles remain saved
until you deliberately delete them from Buyer Profiles.
The sidebar displays the latest successful autosave time.

DEFAULT LISTING FORMAT

1961 Topps Robin Roberts #20 VG (Light corner wear) - $7.00

Blank grades or flaws are omitted cleanly. A Flaw(s) value of None is also
removed completely from the copied listing.

TIP: Image files do not need to be listed in the spreadsheet. Set the base image
folder once, and Card Sale Manager will use the year, player, and card number to
find likely matches.
